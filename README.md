# RM Visual Formulas

Biblioteca de Fórmulas Visuais para o ERP RM.

O objetivo deste projeto é centralizar exemplos práticos de fórmulas utilizadas nos diversos módulos do RM, permitindo consulta, aprendizado e reutilização.

## Conteúdo

- Financeiro
- Compras
- Estoque
- Fiscal
- Contabilidade
- Patrimônio
- RH
- Educacional
- Framework
- Integrações

## Objetivos

- Compartilhar boas práticas
- Disponibilizar exemplos reais
- Facilitar consultas
- Incentivar contribuições da comunidade
