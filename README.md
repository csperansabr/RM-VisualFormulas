# RM Visual Formulas

Biblioteca colaborativa de Fórmulas Visuais para a Linha ERP RM da TOTVS.

O objetivo deste projeto é centralizar exemplos práticos de fórmulas utilizadas nos diversos módulos e processos do RM, permitindo consulta, aprendizado, reutilização e manutenção pela comunidade.

## Objetivos

- Compartilhar boas práticas
- Disponibilizar exemplos reais
- Facilitar consultas
- Incentivar contribuições da comunidade

## Organização do repositório

As fórmulas são organizadas por módulo ou processo do RM:

- [Financeiro](Financeiro/README.md)
- [Compras](Compras/README.md)
- [Estoque](Estoque/README.md)
- [Faturamento](Faturamento/README.md)
- [Fiscal](Fiscal/README.md)
- [Contabilidade](Contabilidade/README.md)
- [Patrimonio](Patrimonio/README.md)
- [Educacional](Educacional/README.md)
- [RH](RH/README.md)
- [Integracoes](Integracoes/README.md)
- [Utilitarios](Utilitarios/README.md)

Cada fórmula deve seguir esta estrutura:

```text
<Modulo>/<NomeDaFormula>/
├── README.md
└── formula.txt
```

Consulte o [padrão de fórmulas](docs/padrao-formulas.md) para conhecer os requisitos de documentação.
